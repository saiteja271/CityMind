# Game Systems Summary

| System | Description |
|--------|-------------|
| World | Tile grid, terrain, zones, pollution |
| Buildings | 20+ types, cost, capacity, employees, influence |
| Roads | Placement, connection graph, pathfinding |
| Citizens | Full agent model with needs & schedule |
| AI | Utility scoring + state priorities |
| Economy | Budget, tax, maintenance, incomes |
| Time | Pause, 1x–8x, day/month/year |
| Environment | Weather, pollution, day/night |
| Events | Random dynamic events |
| Advisor | State-based recommendations |
| Housing | Capacity vs population |
| Employment | Jobs from buildings, unemployment |
| Happiness | Multi-factor calculation |
